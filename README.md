# Telegram Music Bot

Telegram-бот для поиска музыкальных композиций и прослушивания аудио. Проект поддерживает несколько источников музыки и использует единую архитектуру адаптеров для работы с разными API.

## Возможности

- Поиск музыкальных композиций по названию и исполнителю.
- Получение списка найденных треков.
- Прослушивание выбранной композиции непосредственно в Telegram.
- Сохранение истории поисковых запросов.
- Поддержка нескольких музыкальных источников.
- Возможность добавления новых источников без изменения основной логики бота.

## Поддерживаемые источники

### Jamendo

Используется официальный API музыкальной платформы Jamendo.

Возможности:
- Поиск композиций по названию и исполнителю.
- Получение информации о треках и исполнителях.
- Получение обложек и ссылок на аудио.
- Проверка разрешения на скачивание композиции через `audiodownload_allowed`.

Для работы необходим `client_id`, полученный на платформе Jamendo.

API: https://developer.jamendo.com/v3.0

### HitMoz

Используется публичный REST API проекта HitMoz Parser.

Возможности:
- Поиск композиций по названию и исполнителю.
- Получение информации о найденных треках.
- Получение ссылок на прослушивание и скачивание аудио.
- Получение списка популярных композиций.

API: https://bakha.me/hitmoz/

Для получения поисковых результатов отдельный API-ключ в используемой публичной версии не требуется.

HitMoz Parser является сторонним парсером, а не официальным SDK музыкального сервиса. Доступность API и аудиоссылок зависит от работы стороннего сервиса.

## Архитектура проекта

Для взаимодействия с разными музыкальными источниками используется общий интерфейс `BaseSearchAdapter`.

Каждый источник реализует собственный адаптер, который преобразует полученные данные в единый формат. Благодаря этому основная логика Telegram-бота не зависит от структуры ответа конкретного API.

Основные компоненты:

- `BaseSearchAdapter` — базовый абстрактный класс для адаптеров музыкальных источников.
- `JamendoAdapter` — адаптер для работы с Jamendo API.
- `HitMozAdapter` — адаптер для работы с HitMoz API.
- `Track` — единая модель музыкальной композиции.
- `ResultSearch` — общая модель результата поиска.

### Принцип работы

1. Пользователь отправляет запрос боту.
2. Активный адаптер выполняет поиск в выбранном музыкальном источнике.
3. Полученные данные преобразуются в общий формат.
4. Бот отображает найденные композиции.
5. Пользователь выбирает трек и получает аудио.

Такая структура позволяет добавлять новые музыкальные источники, реализуя соответствующий адаптер, без необходимости переписывать обработчики Telegram.

## Используемые технологии

- **Python** — основной язык разработки.
- **pyTelegramBotAPI** — взаимодействие с Telegram Bot API.
- **Requests** — выполнение HTTP-запросов к API.
- **Peewee** — работа с базой данных.
- **Loguru** — логирование.
- **python-dotenv** — загрузка конфигурации из `.env`.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Nimbus-P/TG_BOT-learning-project.git
cd TG_BOT-learning-project
```

### 2. Создание виртуального окружения

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

Linux / macOS:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корне проекта.

```env
BOT_TOKEN=your_telegram_bot_token
API_KEY=your_API_KEY
```

`BOT_TOKEN` — токен Telegram-бота, полученный через [@BotFather](https://t.me/BotFather).

`JAMENDO_CLIENT_ID` — идентификатор приложения, зарегистрированного в Jamendo.

Для использования HitMoz отдельный ключ в текущей публичной версии API не требуется.

Не публикуйте файл `.env` и не добавляйте реальные токены и ключи в Git-репозиторий.

### 5. Выбор музыкального источника

Активный источник задаётся через конфигурацию проекта.

Для использования Jamendo:

```python
ADAPTER = JamendoAdapter()
```

Для использования HitMoz:

```python
ADAPTER = HitMozAdapter()
```

Основные обработчики бота взаимодействуют с адаптером через общий интерфейс `BaseSearchAdapter`.

### 6. Запуск бота

```bash
python main.py
```

## Добавление нового музыкального источника

Архитектура проекта предусматривает расширение за счёт новых адаптеров.

Чтобы добавить новый источник:

1. Создать класс адаптера на основе `BaseSearchAdapter`.
2. Реализовать получение результатов из API нового источника.
3. Преобразовать полученные данные в общую модель `Track`.
4. Вернуть результат в едином формате.
5. Подключить адаптер через конфигурацию проекта.

Таким образом, интеграция нового API не требует изменения основной логики поиска, обработки пользовательских запросов и взаимодействия с Telegram.

## Примечание

Проект создан в учебных целях для изучения Python, работы с HTTP API, обработки данных, объектно-ориентированного программирования и разработки Telegram-ботов.

Доступность композиций, возможность их прослушивания и скачивания определяются условиями соответствующих музыкальных источников. Используйте аудиоматериалы в соответствии с правилами сервисов и законодательством об авторском праве.
